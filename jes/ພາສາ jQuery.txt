5. ຮູບແບບຄໍາສັ່ງຟື້ນຖານຂອງພາສາ jQuery
	jQuery ອອກແບບມາໃຫ້ເລື່ອກເອົາ HTML element(element ໝາຍເຖິງ tag ຂອງ HTML ) ແລະ ກຳນົດ 
action ໃຫ້ກັບຕົວເຮົາເລືອກນັ້ນ ເຊິ່ງມີຮູບແບບດັ່ງນີ້:

  $("selector").action()
	$ ເປັນເຄື່ອງໝາຍເພືອເຂົ້າເຖິງ jQuery
	selector	ສ່ວນທີ່ເລືອກ
	action	ຄື່ຕົວໃຫ້ກຳນົດ selector ທຳງານ

  - ການເລື່ອກ tag element
	$("p") ເລືອກ tag p ທັງໝົດ
  - ການເລືອກ class ແມ່ນດ້ວຍຍາລັກ ' . '
	$(".test")  ເລືອກ tag ທັງໝົດທີ່ມີ class ຊື່ວ່າ  test
  - ການເລືອກ id ແມ່ນດວ້ຍສັນຍາລັກ ' # '
	$("#test") ເລືອກ tag ທັງໝົດທີ່ມີ id ຊື່ວ່າ test
  - ການເລືອກຮູບຕ່າງໆ
	- $("*")	ໝາຍເຖິງການເລືອກທັງໝົດ ຂອງ element
	- $(this)	ໝາຍເຖິງເລືອກຂໍ້ມູນໃນແທັກນີ້
	- $("p.text") ໝາຍເຖິງການລະບຸ ຊື່ແທັກ ພ້ອມກັບ ຊື່ class.
	- $("$new1,$new2")  ໝາຍເຖິງການເລືອກ id ເພື່ອໃຫ້ທຳງານພ້ອມກັນ 2 ຕົວຂື້ນໄປ

7. ເຮົາມີຂໍ້ມູນດັ່ງນີ້:
   <p class="a">click toggle</p>
    <p class="b">dblclick toggle</p>
    <button type="button"class="b_a">click</button>
    <button type="button"class="b_b">dblclick</button>
ຈົ່ງຂຽນ jquery ໃຫ້ທຳງານດັ່ງນີ້:
 - ເມືອກົດໃສ່ປຸ່ມ  click ແລ້ວໃຫ້ຄຳວ່າ click toggle ນັ້ນຫາຍໄປ ແລະ ຄຣີກໃສ່ອີກຄັ້ງກໍໃຫ້ກັບມາສະແດ່ງຜົນຄື່ເກົາ
- ເມືອເຮົາດັບເບີ້ນຄຣີກໃສ່ຄໍາວ່າ dblclick ໃຫ້ໃຫ້ຄຳວ່າ dblclick toggle ນັ້ນຫາຍໄປ
 ແລະ ເມືອໃສ່ດັບເບີ້ນຄຣິກໃສ່ອິກຄັ້ງໃຫ້ກັບມາສະແດ່ງຜົນຄືເກົາ

  <script src="jQuery.js"></script>
    <script>
        $(function(){
            $('.b_a').click(function(){
                $('.a').toggle()
            })
          
            $('.b_b').dblclick(function(){
                $('.a').toggle()
            })
        
        })
    </script>
</head>
<body>
    <p class="a">click toggle</p>
    <p class="b">dblclick toggle</p>
    <button type="button"class="b_a">click</button>
    <button type="button"class="b_b">dblclick</button>
</body>
